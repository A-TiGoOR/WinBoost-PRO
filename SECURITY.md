# Security

WinBoost PRO V3 Enterprise is distributed as a hardened Windows Portable application. Release packages use obfuscated first-party JavaScript, a minified PowerShell backend, runtime integrity verification, and published SHA-256 checksums. Releases contain no embedded secrets and Software Deployment is limited to an approved package catalog.

## Verify downloads

Download releases only from the official GitHub Releases page and compare the Portable EXE hash with `SHA256SUMS.txt`.

## Report a vulnerability

Please report security concerns privately to the project maintainer with a clear reproduction, impact assessment, and affected version. Do not include sensitive customer data in reports. Allow reasonable time for investigation before public disclosure.
